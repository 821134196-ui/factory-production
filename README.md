# 工厂生产记工

手机网页和微信小程序共用后端，支持组长批量填写预制块、浇注料、装车和卸车，员工查看本人工作量与工资，管理员查看统计、发货、库存和月度盘点。仅支持短信验证码登录。

## 本地启动

需要 Node.js 22.13 以上。

1. 执行 npm ci。
2. 将 .env.example 复制为 .env，填写 ADMIN_PHONE、APP_SECRET 和腾讯云短信配置。npm run secret 可生成随机密钥。
3. 执行 npm start，访问 http://127.0.0.1:3188 。手机访问需设置 HOST=0.0.0.0 并访问电脑局域网地址。

没有私有资料时启动空系统，只初始化配置手机号对应的总管理员，不创建真实员工、客户、产品或历史记录。可由管理员维护人员与产品，也可恢复自己的私有资料。

## 私有数据

真实人员、手机号、客户、产品、工资单价、业务规则及 Excel 模板放在 private-data/；数据库和附件放在 data/；密钥放在本地 .env 配置中。这些目录和文件均不提交 Git、不进入 Docker 镜像。

- npm run privacy:backup：生成仅本地保存的完整私有备份包。
- node scripts/privacy.js restore --from 备份包路径 --target 新项目目录：校验并恢复资料，不覆盖已有私有资料或数据库。
- npm run privacy:check：检查待发布文件，不输出敏感内容。
- npm run privacy:release：生成不带旧 Git 历史的干净代码目录。

原始 Excel 的隐藏内容、缓存和历史输入也可能含业务信息，因此原文件及正式导出模板全部通过私有包迁移。仓库只提供空白 JSON 配置示例，不随代码公开业务工作簿。恢复私有模板后，原格式导出继续使用原版式。

已有含真实资料的旧提交仍留在本地原仓库与本地备份中。发布必须从干净目录创建新仓库；不要将旧仓库的分支、标签或提交历史推送到公开仓库。详见 PRIVACY.md。

## 验证

npm test 运行本地可用的测试。公开仓库包含合成数据测试；有真实表格的本地环境还会运行被忽略的历史回归测试。npm run check 检查代码和页面配置；npm run test:docker 验证独立的 Docker 部署及持久化，不发送真实短信。

Docker 部署见 DOCKER.md。
